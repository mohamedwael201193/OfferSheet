Install Qloo's official local server (agent setup)

This wires Qloo's own MCP server into your agent — it is not an OfferSheet server, and it adds no new OfferSheet surface. The verdict itself still runs in the hosted app.

npm install --global @qloo/qloo-harness
qloo mcp

Then add this block to your agent's MCP config — .mcp.json for Claude Code, or the MCP settings file for Cursor. The server name is your local label; the command is Qloo's verified invocation.

{
  "mcpServers": {
    "qloo": {
      "command": "qloo",
      "args": ["mcp"]
    }
  }
}

If the key is missing, Qloo's own setup reports it — run qloo setup --status and follow its prompt. OfferSheet never invents a verdict while the key is missing, and your key never leaves the server: receipts carry hashes and request IDs, never keys.
