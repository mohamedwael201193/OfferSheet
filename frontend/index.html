Illustrative arithmetic on the recorded trial. Being wrong by 100 tickets = $12,000 of guarantee exposure (100 × 120 = 12,000). That 100-ticket gap is hypothetical — not a measured outcome, not a real loss, and not a prediction.

A promoter signs a guarantee with a number in mind. OfferSheet makes that number explicit — tickets to break even — and shows exactly which audience evidence produced it, so the signature is a decision, not a guess.

How it works

Three steps, then a signature.

  1. Enter the offer. Artist, city, guarantee, ticket price.
  2. Run the verdict. Break-even count, audience evidence, receipts.
  3. Check before you sign. Replay any receipt; re-rank without the top pick.

How this verdict was made: every Qloo-backed claim carries a SHA-256 hash and a request ID, and every receipt can be clicked to re-run the exact call. A match means the same IDs in the same order; a mismatch is surfaced, never hidden. Legs with no upstream request ID show “—” and carry an argument hash instead — “—” is not a missing value to fill, and no request ID is ever invented.

What it refuses to do

Fail-closed, on purpose.

No verdict without live evidence

If the evidence legs fail, the verdict is withheld with a visible reason — never a mock number.

No sellout percentage without capacity

Unknown room size means tickets needed only — never a percentage invented from nothing.

No headcount, no sales prediction

Break-even is arithmetic, not a forecast. Attendance and sales are never predicted.

No personal data

Aggregate audience signals only. No names, no emails, no individual behavior.

Not a booking agent, not a ticket seller

It answers one money question before signing. It books nothing and sells nothing.
